# Meridian Strength: 8-Week Intermediate Upper/Lower

Author: R. Kastner, CSCS
Version 3.2 (revised)

A four-day upper/lower split for lifters with roughly a year of consistent
barbell training. Progression is double progression: add reps inside the
prescribed range, then add load and reset to the bottom of the range.

## Weekly structure

| Day | Session |
|---|---|
| Mon | Upper A (horizontal press focus) |
| Tue | Lower A (squat focus) |
| Thu | Upper B (vertical press focus) |
| Fri | Lower B (hinge focus) |

## Upper A

1. Barbell bench press, 4 x 5-8 @ RPE 7-8
2. Chest-supported row, 4 x 8-12
3. Incline dumbbell press, 3 x 8-12
4. Face pull, 3 x 15-20
5. EZ-bar curl, 3 x 10-12

## Lower A

1. Back squat, 4 x 5-8 @ RPE 7-8
2. Romanian deadlift, 3 x 8-10
3. Walking lunge, 3 x 10 per leg
4. Standing calf raise, 4 x 12-15
5. Hanging leg raise, 3 x max quality reps

## Upper B

1. Standing overhead press, 4 x 5-8
2. Weighted pull-up, 4 x 5-8
3. Dumbbell bench press, 3 x 8-12
4. Lateral raise, 4 x 12-20
5. Overhead triceps extension, 3 x 10-12

## Lower B

1. Conventional deadlift, 3 x 3-5 @ RPE 8
2. Front squat, 3 x 6-8
3. Bulgarian split squat, 3 x 8-10 per leg
4. Seated calf raise, 4 x 15
5. Back extension, 3 x 12-15

## Deloads and progression

Weeks 4 and 8 are deloads: keep the same lifts, drop to two thirds of working
load, cut one set from every exercise. Do not push top sets past RPE 8 outside
of week 7. If bar speed on the main lift drops for two sessions running, hold
load and add a rep instead of adding weight.
